1Approval 機能群の切り分けとプライシング

2026-09-20
目次結論：基本＋7オプション切り分けの原則機能群ごとの中身規模による変動初期費用見積例値付けの根拠とリスク

エンタープライズ向けに、機能をオプションとして切り分ける場合の提案です。73画面を「誰が使うか」で束ね直しています。

結論：基本＋7オプション

基本料金を月額 9.8万円のまま残し、そこに7つのオプションを乗せます。全部入れると月額 56.6万円＋ユーザー課金です。

切り分けの原則

機能ではなく、誰が使うかで束ねます。ここを間違えると、安いプランで人数を増やす抜け道ができます。

  1. 管理者が使う機能は定額。総務・購買・情シス・経理の何人かしか触らないので、人数で取っても伸びません。
  2. 現場の全員が触る機能はユーザー課金。Agent Purchase は使う人が増えるほど価値も原価も上がります。
  3. 外部システムとの接続は接続数課金。実装も保守も接続の本数に比例します。
  4. 統制の根幹は Core から外さない。予算・ルール・監査ログ・権限をオプションにすると、「統制のない購買ツール」が売られることになります。それは製品の説明が破綻します。

この原則から、分類の確定と差異の処理も Core に入れます。どちらも台帳が正しく埋まるための条件で、これがないと会計に出せません。

逆に、モノ管理は外せます。購買の統制だけが欲しい会社（既に備品台帳を持っている、あるいは管理するモノが少ない）が実際にあるからです。LP でも資産管理は付加機能と位置づけています。

機能群ごとの中身

Core ¥98,000 / 月（21画面）

購買明細台帳、分類の確定、検収と差異の処理、支出分析、予算設定、ルール設定、通知設定、権限とロール、拠点、監査ログ、初期移行、購買先EC接続1本、承認基盤接続1本、スマホ検収。

これだけで「承認したら発注が終わっている」が成立し、会計に出せるところまで行きます。現行の Goods の価格をそのまま置いています。既存顧客の値上げにはしません。

モノ管理 +¥48,000 / 月（23画面）

備品・資産、個体詳細、在庫、拠点間の移動、期限、貸出（カレンダー含む）、棚卸、点検・修理、廃棄・除却、QRラベル、スマホ3画面。

画面数では Core を上回りますが、値付けは半分にしています。備品管理単体の相場（アストロラボ等）が月額3〜5万円帯で、そこと並べられるからです。

リース・固定資産 +¥38,000 / 月

リース契約の台帳と登録、支払スケジュールの自動生成、固定資産ソフトへの連携。

2027年4月の新リース会計基準が値付けの根拠です。オペレーティング・リースもオンバランスになり、契約の棚卸しが必要になります。期限が決まっているので、このオプションは前年度から売れます。

会計・経費自動連携 +¥38,000 / 1接続

勘定奉行、PCA、freee、マネーフォワード、楽楽精算、バクラク。接続ごとに項目マッピング、テスト出力、接続ログ。

値付けの根拠は実装と保守の工数です。先方のバージョンアップごとに確認が必要で、これは減りません。CSV出力は Core に含め、API連携だけを有償にします。手作業を残して金を取る形にはしません。

IT資産 +¥58,000 / 月（3画面）

MDM連携の未登録検出、SaaSライセンス台帳、契約の詳細。

画面は3枚ですが、回収できる金額が大きいのでこの価格です。ワイヤーの例では休眠・退職者残存で12席、月 ¥33,000・年 ¥396,000 の削減余地が出ています。ライセンスの多い会社ほど投資回収が早くなります。

Agent Purchase +¥400 / ユーザー月（6画面）

AIレコメンド、出張手配、カタログ、申請、申請の詳細、承認。最低料金 ¥98,000（245人相当）。

唯一のユーザー課金です。推論のコストが人数と回数に比例するので、定額にすると大企業で逆ざやになります。逆に小さく始められるので、現場の一部に先行導入してから広げる売り方ができます。

人事マスター連携 +¥68,000 / 月（2画面）

Entra ID / 人事システムを正とした差分同期、付与ルール、SCIM でのプロビジョニング。

IT資産オプションと対で使うと効きます。単体でも成立しますが、セットで ¥110,000（¥16,000引き）にするのを推奨します。

規程・標準品 +¥88,000 / 月（2画面）

社内規程のRAG学習、全社標準品カタログ。

規程の取込・条文の構造化・ルール候補の抽出に人手がかかるので、月額に初年度の伴走分を乗せています。Agent Purchase を入れていない会社には売らない方がいいです。効かせる先の申請画面がないためです。

規模による変動

定額部分は拠点数で係数をかけます。ユーザー数では取りません。管理工数は人数ではなく拠点数とロケーション数で伸びるからです。

拠点数定額部分の係数目安
1〜3拠点×1.0基準
4〜10拠点×1.4複数工場・営業所
11〜30拠点×1.8全国展開
31拠点以上個別チェーン・多拠点

接続数は実数です。購買先ECは2本目から +¥18,000 / 月、承認基盤（kintone と M365 の両方など）は2本目から +¥28,000 / 月。会計・経費は1接続 ¥38,000 をその都度。

Agent Purchase のユーザー数は、実際に申請・承認をした人の月次ユニーク数で数えます。登録だけして使っていない人は課金しません。負けているようですが、全社展開の障壁を下げるほうが長期では大きくなります。

エンタープライズで必ず聞かれるものは別途です。SSO（SAML / OIDC）は Core に含め、監査ログの7年保存も Core に含めます。これを有償にすると審査で落ちます。SLA 保証（99.9%）、専用サポート窓口、リージョン指定は Enterprise プランとして +¥120,000 / 月。

値付けの根拠とリスク

根拠は3つです。

回収できる金額。ワイヤーの数値で言えば、重複購買の抑止が月 ¥286,400、SaaS の休眠席が月 ¥33,000、退職者残存が月 ¥48,500。B社規模なら月額の料金を回収できる水準になります。

単体製品の相場。備品管理クラウドが月 3〜5万円、SaaS 管理が 5〜15万円、購買管理（大手）が 30万円以上。個別に並べられても負けない価格にしてあります。

提供原価。推論コストと接続の保守だけが人数・本数に比例します。そこだけを変動にし、残りは定額にしています。

リスクも書いておきます。

細かく切りすぎると販売が重くなります。7オプションは、提案書の作成と見積の説明に時間を食います。実際には Standard（Core＋モノ管理）、Enterprise（＋IT資産＋人事連携＋連携API） の2バンドルを先に見せ、個別オプションは聞かれたら出すのが現実的です。

統制機能をオプションにしない。予算・ルール・監査ログ・権限を外すと、安いプランが「統制のない購買ツール」になります。製品の説明が成り立たなくなるので、ここは売上を捨てても Core に残します。

既存顧客の扱い。現行の 9.8万円には備品管理が含まれる前提で売っています。切り分けを入れるなら、既存契約は Core＋モノ管理を 9.8万円のまま据え置きにするのが筋です。途中で値上げに見える変更は、信用の損が大きいです。

未確定の前提。Agent Purchase のユーザー単価 ¥400 は、推論コストの実測前の数字です。1人月あたりの問い合わせ回数が読めたら見直します。
