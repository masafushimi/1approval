課題と背景
Googleフォームの権限散逸・事故

個別フォーム作成による権限・承認ルートの散逸。生のスプレッドシートにアクセスさせると関数破壊や全社データ漏洩のリスクが深刻化。

アーキテクチャの解答
GAS HTML Service 統合ポータル

1つのHTML Webポータルで全権限・画面を動的制御。バックエンドのGoogleスプレッドシートは一般ユーザー非公開のDBとして完全隠蔽。

1approval 統合管理Hub
経理・管理者ポータル (5/mock)

経理部門は1approval管理アプリ画面（`5/mock`）で全社一括請求・L3明細確認・勘定奉行/PCA自動仕訳・BI分析を一元実行。

システム構築要件 ＆ 画面分離・管理方針

フロントエンド (現場申請者・上長)

  • ログイン・権限統合: Google IDから部署・役職に応じた入力項目や承認ルートをHTML側で動的制御。
  • kintone申請フィールド完全互換: 出張者・出張先・目的・スケジュール・ホテル/航空券/経費テーブル・金額集計の完全再現。
  • cXML パンチアウト: ポータルから1approval Hub経由でピカパカ/モノタロウをモーダル起動。
  • Google Chat Card承認: 上長はChatメッセージからワンクリック承認・即時自動PO発注。

バックオフィス (経理・全社管理者: 5/mock)

  • 月1回の一括請求・突合: 全拠点のピカパカ・モノタロウ等購買を会社宛1枚の請求書に集約・一括処理。
  • 会計仕訳連携 (PEPPOL): L3詳細データ（品目・SKU・区間等）を保持し、勘定奉行/PCA/freee等へ自動仕訳出力。
  • ダイナミック・ポリシー集中管理: 価格変動許容値（`priceThreshold`: 20%など）や役職規定の一元設定。
  • 全社購買BI分析: 拠点別・カテゴリ別支出のリアルタイム可視化と不正アラート検知。

function executePunchoutSetup(serviceType, buyerCookie) {
  const userEmail = Session.getActiveUser().getEmail();
  const payload = {
    cXML: {
      "@payloadID": Utilities.getUuid(),
      "@timestamp": new Date().toISOString(),
      Header: {
        From: { Credential: { "@domain": "DUNS", Identity: "eichiii-dev" } },
        To: { Credential: { "@domain": "DUNS", Identity: "pikapaka-btm" } },
        Sender: { Credential: { "@domain": "NetworkID", Identity: "punchout_eichiii_dev", SharedSecret: "jN7!xR2pQ9@vL4wZ" }, UserAgent: "PikapakaSystem/1.0" }
      },
      Request: {
        PunchOutSetupRequest: {
          "@operation": "create",
          BuyerCookie: buyerCookie,
          ItemIn: [{
            "@quantity": "1", "@lineNumber": "1",
            ItemID: { SupplierPartID: "SETUP-REQUEST" },
            ItemDetail: { Description: { "@xml:lang": "en", "#text": "User Registration Request" }, UnitOfMeasure: "EA" },
            Extrinsic: [
              { "@name": "register_email", "#text": userEmail },
              { "@name": "service", "#text": serviceType }
            ]
          }]
        }
      }
    }
  };

  const options = {
    method: "post",
    contentType: "application/json",
    headers: { "x-api-key": HUB_CONFIG.hubApiKey },
    payload: JSON.stringify(payload),
    muteHttpExceptions: true
  };

  const response = UrlFetchApp.fetch(`${HUB_CONFIG.baseRelayServerUrl}/api/v1.0/punchout/setup${HUB_CONFIG.urlModeSuffix}`, options);
  return JSON.parse(response.getContentText());
}
